# Rabbit Hole Spanish Translation

English

This is an unofficial Spanish translation project for Rabbit Hole.
The goal is to translate dialogues, menus and interface text.

Progress will be uploaded gradually so people can compare the original text with the translated version.

---

Español

Este es un proyecto de traduccion no oficial al español de Rabbit Hole.
El objetivo es traducir dialogos, menus y textos de la interfaz.

Se iran subiendo avances para que se puedan comparar los textos originales con los traducidos.
